# Контрольная работа №2 — ShopProject

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Учебный магазин компьютерной периферии. Отдельная реализация предметной области КР №1 на Bootstrap; файлы и стили КР №1 не используются.

## Практическая работа №9

Создана главная страница: шапка, Bootstrap-navbar, hero из двух колонок, три преимущества, популярные товары и подвал. Сетка `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, промежутки `g-4` и utility-классы Bootstrap.

## Подключение Bootstrap

В итоговой версии Bootstrap 5.3.8 подключён локально, без CDN. Compiled CSS и JS Bundle находятся в `vendor/bootstrap/css/bootstrap.min.css` и `vendor/bootstrap/js/bootstrap.bundle.min.js`. Собственный `css/custom.css` загружается после Bootstrap. JS Bundle включает Popper и обеспечивает navbar, dropdown, modal и accordion.

Исходники дистрибутива: [Bootstrap CSS](https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css), [JS Bundle](https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js). Лицензия MIT сохранена в `vendor/bootstrap/LICENSE`.

В коммите №9 использовался CDN Bootstrap 5.3.3, в №10 — CDN 5.3.8; в №11 выполнено дополнительное задание по локальному подключению.

## Практическая работа №10

Добавлены `catalog.html`, `product.html`, `order.html`, единая navbar с активной страницей, карточки каталога, информационные сообщения, модальное окно быстрой заявки и FAQ accordion. Страница товара содержит описание, цену и адаптивную таблицу характеристик. Bootstrap обновлён до 5.3.8 согласно методичке №10.

Компоненты: `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `breadcrumb`, `table`.

Основная форма содержит имя, email, телефон с префиксом +7, выбор товара, комментарий и обязательное согласие. У каждого поля есть `label`. Кнопка модального окна связана с формой и запускает встроенную проверку обязательных полей. После успешной проверки выводится сообщение о демонстрации. Сервера нет, данные не отправляются и не сохраняются; кнопка сброса очищает форму и сообщение.

Проверка: пройти по ссылкам навигации; открыть/закрыть мобильное меню, modal (также Escape) и обе секции accordion; проверить обязательные поля и ошибочный email, заполнить обе формы, затем сбросить основную форму.

7. В основной форме проверить пустое имя, неверный email, обязательное согласие, успешную демонстрацию и сброс. Данные не должны уходить по сети.
8. На странице товара переключить оба вопроса FAQ.
9. Отключить внешнюю сеть и повторить проверку: стили и интерактивные компоненты должны работать без CDN.
